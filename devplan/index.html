Deploy Control API บน Main Server (:8070)

Main Server
▼

Control API คือตัวแจก Rule Bundle ให้ Edge ดึงทุก 5 วิ ถ้าไม่รัน → กฎ WAF ที่สร้างใน Dashboard ไม่ถึง Edge เลย

⚠️

SSH เข้า Main Server (178.104.53.123) ก่อน

Main Server — เพิ่ม Control API ใน docker-compose.yml
# เปิดไฟล์แก้ไข
nano /root/waf_project/docker-compose.yml

# เพิ่มใน section services: (ก่อนบรรทัด volumes:)
  control-api:
    build: ./cdn/control-api
    container_name: waf-control-api
    ports:
      - "8070:8070"
    volumes:
      - ./modsecurity/custom-rules:/src/custom-rules:ro
      - control_data:/data
    environment:
      CONTROL_TOKEN: "your-secret-control-token"
    restart: unless-stopped
    networks:
      - waf-net

# เพิ่มใน section volumes: ด้วย
  control_data:

# Build และ Start
cd /root/waf_project && docker compose up -d --build control-api
curl http://localhost:8070/healthz
ℹ️

ต้องทำบน Edge Node ด้วย — แก้ /root/edge_node/.env เพิ่ม CONTROL_API_URL=http://178.104.53.123:8070 และ CONTROL_TOKEN=***REDACTED*** แล้ว docker compose up -d --force-recreate edge-node

ตั้งค่า Firewall (UFW) บนทั้งสองเครื่อง

MainEdge
▶

ตอนนี้ทุก Port เปิด Public — อันตรายมาก ต้องล็อคให้รับเฉพาะ IP ที่จำเป็น

⚠️

ทำ ufw allow 22 ก่อน เสมอ ไม่งั้นจะถูกล็อคออกจาก SSH!

Main Server (178.104.53.123)
ufw default deny incoming && ufw default allow outgoing
ufw allow 22/tcp
ufw allow 80/tcp && ufw allow 443/tcp
# อนุญาตเฉพาะ Edge Node เข้า WAF Port + Control API
ufw allow from 45.154.26.91 to any port 8080
ufw allow from 45.154.26.91 to any port 8070
ufw --force enable && ufw status numbered
Edge Node (45.154.26.91)
ufw default deny incoming && ufw default allow outgoing
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw --force enable && ufw status

Real-time Health Check ทุก Edge Node

Main
▶

ให้ Dashboard แสดงสถานะ Online/Offline ของ Edge Node ทุกตัวแบบ Real-time แทน Mock

Main Server — เพิ่ม Health Check ใน api/cdn.py
EDGE_HEALTH_URLS = {
    "TH": "http://45.154.26.91/healthz",
    # "SG": "http://<SG_IP>/healthz",
}

@router.get("/nodes")
async def get_nodes(current_user = Depends(require_viewer_or_above)):
    results = {}
    async with httpx.AsyncClient(timeout=3.0) as client:
        for region, url in EDGE_HEALTH_URLS.items():
            try:
                r = await client.get(url)
                results[region] = {"status": "online", "latency_ms": r.elapsed.microseconds//1000}
            except:
                results[region] = {"status": "offline", "latency_ms": None}
    return results
